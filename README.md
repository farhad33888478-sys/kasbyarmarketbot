# ربات Market_IR برای پیام‌رسان بله

ربات معرفی کسب‌وکار و فروشگاه با جریان کامل: ثبت → تایید مدیر → انتشار در کانال → ۳۰ روز رایگان → تمدید بر اساس تعرفه.

## امکانات

ربات شامل **دو مسیر کاملاً مستقل و جدا از هم** است (منو، مراحل، صف تایید ادمین، جدول دیتابیس و کانال انتشار هرکدام جداست):

### ۱) ثبت کسب‌وکار (🏪)
- فرم چندمرحله‌ای کامل (نام، دسته‌بندی، توضیحات، تماس، آدرس، عکس)
- ارسال درخواست برای تایید به گروه ادمین با دکمه‌های ✅ تایید / 🚫 رد
- انتشار خودکار در **کانال کسب‌وکارها** (`PUBLIC_CHANNEL_ID`) پس از تایید
- ۳۰ روز اشتراک رایگان خودکار برای هر آگهی تاییدشده
- جدول پلن‌های قیمتی برای تمدید (قابل ویرایش)
- دریافت رسید پرداخت از کاربر و تایید/رد توسط ادمین
- یادآوری خودکار چند روز قبل از پایان اشتراک
- حذف خودکار آگهی از کانال پس از پایان اعتبار (در صورت عدم تمدید)

### ۲) ثبت پوستر تبلیغاتی (📢)
- فقط ارسال یک عکس پوستر + توضیح کوتاه (بدون فرم کسب‌وکار)
- ارسال برای تایید به همان گروه ادمین، اما با دکمه‌های مجزا (✅ تایید پوستر / 🚫 رد پوستر)
- انتشار در **کانال مستقل پوستر تبلیغات** (`POSTER_CHANNEL_ID`) — کاملاً جدا از کانال کسب‌وکارها
- بدون بحث اشتراک/۳۰ روز رایگان/پرداخت — فقط تایید یا رد

هر دو مسیر در دیتابیس هم در دو جدول جدا (`businesses` و `posters`) ذخیره می‌شوند و هیچ داده‌ای بین آن‌ها مشترک نیست.

### ۳) کراس‌پست خودکار به تلگرام (📤)
- بعد از تایید هر کسب‌وکار یا پوستر در بله، همان آگهی به‌صورت خودکار در یک **کانال تلگرام جداگانه** هم منتشر می‌شود.
- ربات تعاملی (فرم، تایید ادمین) فقط روی بله اجرا می‌شود؛ تلگرام فقط گیرنده‌ی نهایی آگهی‌های تاییدشده است.
- چون `file_id` عکس در بله روی تلگرام معتبر نیست، عکس به‌صورت خودکار از سرور بله دانلود و دوباره در تلگرام آپلود می‌شود.
- این قابلیت کاملاً اختیاری است: اگر `TELEGRAM_BOT_TOKEN` در `config.py` خالی بماند، بدون هیچ خطایی غیرفعال می‌ماند و فقط روی بله کار می‌کند.

**تنظیم کراس‌پست تلگرام:**
1. یک ربات در تلگرام با `@BotFather` بسازید و توکن آن را بگیرید.
2. ربات را در دو کانال تلگرام (یکی برای کسب‌وکارها، یکی برای پوسترها) ادمین کنید.
3. در `config.py` مقادیر زیر را پر کنید:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHANNEL_ID` (کانال کسب‌وکارها)
   - `TELEGRAM_POSTER_CHANNEL_ID` (کانال پوسترها)

### ۴) کراس‌پست خودکار به ایتا (📤)
- دقیقاً همان منطق کراس‌پست تلگرام، اما از طریق سرویس `eitaayar.ir`.
- توجه: API ایتایار **یک‌طرفه** است (فقط ارسال پیام/فایل)؛ امکان ساخت ربات تعاملی کامل روی خود ایتا وجود ندارد، چون این پلتفرم سیستم دریافت پیام (getUpdates/webhook) ندارد. پس این هم فقط یک کراس‌پست خودکار است، نه یک ربات مستقل.
- کاملاً اختیاری: اگر `EITAA_TOKEN` خالی بماند، بدون خطا غیرفعال می‌ماند.

**تنظیم کراس‌پست ایتا:**
1. در سایت [eitaayar.ir](https://eitaayar.ir) ثبت‌نام کنید و کانال‌های خود را متصل کنید تا توکن دریافت کنید.
2. کانال ایتا (کسب‌وکارها و پوسترها) را به ایتایار متصل کنید تا اجازه‌ی ارسال داشته باشید.
3. در `config.py` مقادیر زیر را پر کنید (آیدی کانال‌ها بدون علامت @):
   - `EITAA_TOKEN`
   - `EITAA_CHANNEL_ID`
   - `EITAA_POSTER_CHANNEL_ID`

- ذخیره‌سازی در پایگاه داده SQLite (بدون نیاز به سرور جداگانه)

## پیش‌نیازها
- پایتون نسخه ۳.9 یا بالاتر
- یک اکانت در پیام‌رسان بله و ساخت ربات از طریق باتفادر بله (`@botfather` در بله)
- یک کانال عمومی برای انتشار آگهی‌ها + ربات را ادمین کانال کنید
- یک گروه خصوصی برای دریافت درخواست‌های تایید + ربات را عضو/ادمین گروه کنید

## تنظیمات (فایل `config.py`)

1. `BOT_TOKEN`: توکن ربات که از باتفادر بله دریافت می‌کنید.
2. `ADMIN_IDS`: آیدی عددی خودتان (و سایر ادمین‌ها) به‌عنوان لیست.
   - برای گرفتن آیدی عددی خودتان می‌توانید پیامی به ربات ارسال کنید و آیدی `from.id` را در لاگ کنسول یا با یک ربات کمکی مثل `@userinfobot` مشابه (در صورت وجود در بله) پیدا کنید. اگر ابزار مشابه در بله در دسترس نبود، می‌توانید موقتاً در `main.py` مقدار `update` را چاپ کنید تا آیدی خودتان را در لاگ ببینید.
3. `ADMIN_REVIEW_CHAT_ID`: آیدی عددی گروه ادمین (با پیام «برای بررسی» تست کنید و آیدی چت را از لاگ بردارید).
4. `PUBLIC_CHANNEL_ID`: یوزرنیم کانال **کسب‌وکارها** (مثلاً `@market_ir_channel`) یا آیدی عددی کانال.
4b. `POSTER_CHANNEL_ID`: یوزرنیم کانال **مستقل پوستر تبلیغاتی** (مثلاً `@market_ir_ads`) — حتماً باید متفاوت از کانال کسب‌وکارها باشد و ربات باید در هر دو کانال ادمین باشد.
5. `FREE_TRIAL_DAYS`: تعداد روزهای رایگان (پیش‌فرض ۳۰).
6. `PLANS`: جدول تعرفه‌ها؛ هرکدام شامل `title` (عنوان)، `days` (تعداد روز) و `price` (مبلغ به تومان) است. می‌توانید هر تعداد پلن اضافه/حذف/ویرایش کنید.
7. `CARD_NUMBER` و `CARD_OWNER`: اطلاعات کارت بانکی برای دریافت وجه به‌صورت دستی.
   - در صورت تمایل به اتصال درگاه پرداخت آنلاین (مثل زرین‌پال)، باید بخش «انتخاب پلن» در `bot.py` را طوری تغییر دهید که به‌جای نمایش شماره کارت، لینک پرداخت درگاه را بسازد و در کال‌بک درگاه، `db.confirm_payment` و `db.extend_business` را صدا بزند.

## اجرا

```bash
python main.py
```

برای اجرای دائمی روی سرور، پیشنهاد می‌شود از `systemd`، `screen`، `tmux` یا `pm2` (با `python` interpreter) استفاده کنید تا ربات بعد از قطع شدن ترمینال هم زنده بماند. مثال ساده با `systemd`:

```ini
# /etc/systemd/system/market-ir-bot.service
[Unit]
Description=Market IR Bale Bot
After=network.target

[Service]
WorkingDirectory=/path/to/market_ir_bot
ExecStart=/usr/bin/python3 main.py
Restart=always
User=youruser

[Install]
WantedBy=multi-user.target
```

سپس:
```bash
sudo systemctl daemon-reload
sudo systemctl enable market-ir-bot
sudo systemctl start market-ir-bot
```

## ساختار فایل‌ها

| فایل | توضیح |
|---|---|
| `config.py` | تمام تنظیمات قابل تغییر (توکن، آیدی‌ها، پلن‌ها، متن‌ها) |
| `database.py` | لایه‌ی دیتابیس SQLite (کاربران، کسب‌وکارها، پرداخت‌ها) |
| `bale_api.py` | توابع فراخوانی API بله (ارسال پیام، عکس، دکمه و ...) |
| `telegram_api.py` | ارسال پیام/عکس به تلگرام برای کراس‌پست خودکار (اختیاری) |
| `eitaa_api.py` | ارسال پیام/عکس به ایتا برای کراس‌پست خودکار (اختیاری) |
| `keyboards.py` | ساخت کیبوردهای شیشه‌ای و منوها |
| `bot.py` | منطق اصلی: مکالمه‌ی ثبت کسب‌وکار، تایید ادمین، پرداخت |
| `scheduler.py` | بررسی دوره‌ای انقضای اشتراک‌ها و یادآوری/حذف خودکار |
| `main.py` | حلقه‌ی اصلی دریافت پیام‌ها (Long Polling) |

## نکات مهم امنیتی / عملیاتی
- توکن ربات را در جایی عمومی (گیت‌هاب عمومی و ...) قرار ندهید. بهتر است آن را به‌صورت متغیر محیطی `BALE_BOT_TOKEN` تنظیم کنید.
- تایید پرداخت در نسخه فعلی «دستی» است (کاربر رسید می‌فرستد و ادمین تایید می‌کند). این ساده‌ترین و سریع‌ترین روش برای شروع کار بدون نیاز به درگاه بانکی است.
- اگر تعداد کاربران زیاد شود و بخواهید کارایی بهتری داشته باشید، می‌توانید SQLite را به PostgreSQL/MySQL تغییر دهید (فقط لازم است `database.py` بازنویسی شود؛ بقیه‌ی کد بدون تغییر می‌ماند).
- برای امنیت بیشتر گروه ادمین (`ADMIN_REVIEW_CHAT_ID`) را خصوصی نگه دارید و فقط ادمین‌های مطمئن را عضو کنید.

## سفارشی‌سازی سریع متن‌ها
تمام پیام‌های فارسی ربات در فایل `bot.py` (متغیر `HELP_TEXT` و رشته‌های داخل توابع) و `keyboards.py` قرار دارند و به‌راحتی قابل ویرایش هستند.
